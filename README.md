# Khalyd

I build small tools, on-chain apps and bots, and do security research.

## Tools

Free, open source, and small enough to read in one sitting.

| | What it does |
|---|---|
| [invoicepad](https://github.com/khalydmaina/invoicepad) | Invoice maker with no sign-up. Bank transfer or USDC/USDT, with a checked wallet address and QR code. [Use it](https://khalydmaina.github.io/invoicepad/) |
| [keyguard](https://github.com/khalydmaina/keyguard) | Git hook that stops Solana keypairs, EVM keys and seed phrases from being committed. |
| [flatline](https://github.com/khalydmaina/flatline) | Catches bots that run green but do nothing, and pings Telegram when they go quiet. |
| [baseunits](https://github.com/khalydmaina/baseunits) | Exact converter for wei, gwei, lamports and any token decimals. [Use it](https://khalydmaina.github.io/baseunits/) |

## Projects

- [tare](https://github.com/khalydmaina/tare): an AI trader with brakes that tighten where the model has proven it cannot be trusted.
- [sentry](https://github.com/khalydmaina/sentry): ledger-enforced spending limits for AI agent wallets, written in Daml on Canton.
- [brute-force-detection-system](https://github.com/khalydmaina/brute-force-detection-system): evasion-aware brute-force detection and automated response for small businesses.
